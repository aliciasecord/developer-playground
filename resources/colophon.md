# Colophon

## Type (Google Fonts)
- Headings: Recursive (900)
- Body: Public Sans (400)
- Mono: Recursive (300)

## Palette
Style:
  A graph-paper base, a dotted grid behind the numeral, pinks as the only accent color. Light and dark mode supported. The grid nods to a lab notebook: a page meant for daily entries, not a finished showpiece. 

Light Mode: 
  Background: #ffffff (white)
  Background Subtle: #FDF7ED (floral)
  Background Inverse: #333333 (graphite)
  Text: #333333 (graphite)
  Muted Text: #999999 (gray)
  Inverse Text: #FDF7ED (floral)
  Accent Color: #592449 (blackberry cream)
  Accent Hover: #481E3B (midnight violet) 
  
Dark Mode: 
  Background: #333333 (graphite)
  Background Subtle: #222222 (carbon)
  Background Inverse: #FFFFFF (white)
  Text: #FDF7ED (floral)
  Muted Text: #999999 (gray)
  Inverse Text: #333333 (graphite)
  Accent Color: #FFADBB (cherry blossom)
  Accent Hover: #FF99AA (cotton candy)
