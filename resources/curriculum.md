# 365 Micro Dev Projects — HTML/CSS/JS Only

One idea per day for a year. Organized into 36 themed batches of 10, plus a closing batch of 5 week-scale builds. Vanilla HTML/CSS/JS, no frameworks, no build step — pairs with your existing style-guide skill system. Most are single-sitting builds (1–3 hrs); anything marked **(week)** is meant to stretch across several sessions.

Tip: new folder per project (`index.html`, `style.css`, `script.js`), commit early and often. Don't do these in strict order — alternate categories to keep momentum.

### How to sequence this
- Alternate categories rather than working straight down the list — a game next to a form next to a CSS showcase keeps things interesting.
- Save the week-scale batch for slower weeks or when you want a breather from strict single-sitting builds.
- Several projects (341, 342, 345, 348, 350, 351–360, 361, 364) connect directly to things you're already building — good low-stakes places to prototype ideas before committing them to the "real" version.
- Batches 16, 26, and 27 (audio, physics, music) lean canvas-heavy and pair well back-to-back if you're in a "flow state" mood.
