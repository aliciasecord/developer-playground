About the Project

What is Developer Playground?

Developer Playground is a project by Alicia Secord. She wants to turn her Github bar fully green over the next year and learn some new best practices along the way. This project uses Claude Code and VS Code to develop. It is noted in the colophon what resources were used and how.

Colophon

The resources I've used:

  • MODERN NORMALIZE by Sindre Sorhus for my CSS reset layer.
  • This HTML Boilerplate by Manuel Matuzović
  • Various resources from W3SCHOOLS for HTML, CSS, and JS.
  • Various CSS and JS resources from the MOZILLA DEVELOPER NETWORK
  • My favorite CSS Tricks tutorial: FLEXBOX
  • COLOR PALETTE GENERATOR and CONTRAST CHECKER from Coolors

How Claude has been helpful:

  • The ideas for the curriculum.

    I put them in order and rewrote some of them.

  • The initial README file.

    Edited heavily.

  • My theme.css file with every HTML element in it and ready to be styled.

    This may become part of my workflow, because I really liked the structure as a starting place.

  • Quite a bit of the early JS

    It wrote the functions for injecting the header, nav, footer into the HTML; the functions to make the mobile nav work when I got tripped up halfway through; and the functions to make the theme detection work. This element got me thinking about why I trust it with things I don't know how to do rather than with the things I can easily check.

  • The scaffolding for the projects and logs

    Like with the theme.css file, I used Claude to generate the structure for the log.js and projects.js files.
