About This Build

This was the learning build, in that I learned a lot of things that don't work. First, I tried to get Claude to code the landing page for me. But I was so annoyed with what it created that I scrapped it and started over.

I decided to serve up the site header and footer across the project with the app.js file. The theme.js file will detect system light or dark mode and is render blocking.

In the end, I did a lot of this by hand. I decided to start noting in the colophon.md file where Claude wrote things in this repo. The main thing it did was create me a CSS file (theme.css) with everyz HTML element in it. I am using that as my CSS boilerplate.

Once I nailed down the landing page hero design, I created the mobile navigation menu with a hamburger toggle and started this write-up.

Claude helped me with the JS for the mobile hamburger nav, in that I wrote it and asked it to check me when it didn't work. It edited that section of the app.js file.

It finally occured to me why I would want to embed fonts into the CSS file. So I did that. It wasn't hard.

I decided to do a horizontal masonry because it was easier than figuring it out column-wise. I'm winding down Day 004 (at 1:12 a.m. on Day 005) in a very good spot.
